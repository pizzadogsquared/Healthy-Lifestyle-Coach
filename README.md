# Healthy-Lifestyle-Coach

## Getting Started

These instructions are intended to assist in setup for the Bee Balanced Health web application on your local machine for testing.

1. Prerequisites

Please ensure you have Node.js and Git installed on your local machine.

2. Clone the Repository

```bash
git clone https://github.com/pizzadogsquared/Healthy-Lifestyle-Coach.git
cd Healthy-Lifestyle-Coach
```

3. Install Packages

```bash
npm i
```

4. Run Project

```bash
node app.js
```
